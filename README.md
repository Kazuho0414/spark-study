- 原本147問はすべていずれかの模試に1回ずつ入ります。関連するテーマでも異なる判断を問う原問を保持しています。
- 基本は45問・90分。時間制限、即時解説、問題順・選択肢順のシャッフルは設定できます。
- 複数選択は正解となる選択肢をすべて選んだ場合に正解とします。各問に必要な選択数を表示します。
- 原本147問だけの演習と、225問のうち復習期限・苦手だけを対象とした継続復習（未見は除外）があります。復習の誤答は同じセッションの後ろへ自動追加されます。
- 誤りや不足前提の訂正には、元の文面・選択肢と公式参照を保存。原問57は複数選択に訂正し採点保留を解除しました。
- 統合前155問と、今回使わない既存自作問題は履歴参照のためデータに保持し、通常の模試・ランダム・復習には含めません。元155問の資料参照は「記録・参照」から開けます。
- 学習履歴、途中の演習、メモ、選択途中、設定、退避した演習、Google/Firebase同期を維持します。新模試は新しい保存キーを使います。

公式の採点対象45問・90分と分野比率は[Databricksの認定ページ](https://www.databricks.com/learn/certification/apache-spark-developer-associate)および[公式範囲PDF](https://www.databricks.com/sites/default/files/2026-10/databricks-certified-associate-developer-apache-spark-exam-guide-august-2026.pdf)を参照しています。
