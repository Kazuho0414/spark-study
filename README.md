# 合格演習室 — 問題集ライブラリ

https://kazuho0414.github.io/spark-study/

Spark教材（模試180問・類題24問・補強42問）に加え、任意の分野の問題集JSONを画面から追加できます。

## ログインと自動同期

同じ本人Googleアカウントでログインすると、問題集・回答履歴・途中の演習・メモ・設定を自動同期します。
ログイン済みのブラウザでは次回アクセス時もログイン状態を復元します。
回答後、画面復帰時、表示中は30秒ごとに同期します。別端末へ移る前に「同期済み」を確認してください。
通信できない間は端末に保存し、オンライン復帰時に再試行します。ブラウザを閉じた後は送信できません。
同じ演習を両端末で変更し、回答が衝突した場合は別の途中演習として保持します。
メモ等の同時変更は操作中の端末を優先し、統合前の両方の記録をバックアップに残します。
「同期前のバックアップを保存」で取得できます。全体バックアップ画面から元の端末記録を統合できます。

## 時間制限と中断・再開

ホームの「出題の設定」で「時間制限をONにする」を切り替えます。
OFFで始めた演習は時間切れにならず、「中断してホームへ」→「途中のセッション」の「続きから」で再開できます。
回答・表示位置・選択肢順は保持します。途中の時間制限付き演習も、OFFにして再開すれば期限を解除します。
ONに戻した場合は新しい演習から時間制限が付き、既に期限なしにした演習には付け直しません。
ONの演習は離席中も時計が進みます。端末を替える前は「同期済み」を確認してください。

## 分野を指定せず問題集を追加

1. 「問題集の切り替え・追加」を開き「追加用テンプレートを保存」。
2. JSONの問題集ID・タイトル・問題文・選択肢・正解・解説を編集。
3. 「問題集JSONを追加」で取り込み、選択欄から切り替え。

単一正解の2〜8択、グループ別の制限時間、任意の分野・論点、日本語訳に対応します。
履歴と弱点分析は問題集ごとに分離します。問題集IDは上書き不可なので別のIDを使用してください。
追加教材は本人用Firestoreに保存され、公開GitHubリポジトリへはアップロードされません。
JSONは1ファイル3MB・5000問まで、問題集50冊まで。端末の保存容量・クラウド全体の上限にも依存します。
「全問題集・記録をバックアップ」と「全体バックアップを統合」で別途保存・復旧できます。
詳しいデータ形式は「問題データの編集方法.md」を参照してください。

## 構成と移行

公開ページはGitHub Pages、Google認証と保存先はFirebase spark-study-812e6です。
Googleプロバイダー、承認済みドメインkazuho0414.github.io、本人限定Firestoreルールを設定済みです。
Firebase公開設定にサービスアカウント秘密鍵は不要です。ルール変更も今回の更新では不要です。
旧Spark端末記録と旧クラウド記録は初回アクセス・同期時に引き継ぎます。
更新後はすべての端末でページを再読み込みしてください。古いページの保存ボタンは使わないでください。
ローカルHTMLと公開URLの保存場所は異なるため、ローカル版の記録はJSONで引き継ぎます。
公開教材自体はログインせず閲覧できます。本人限定なのはFirestoreの学習記録と追加教材です。
